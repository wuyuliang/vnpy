# 抛售高潮能不能事前过滤掉：负面结果

**问题**：抛售高潮的最后一段完全符合入场条件（放量、大阴线、破结构），进去就是
接刀。能不能加一道门把它挡在外面？

**结论**：**测了七个判别量、三种入场方式，没有一个能同时通过两组样本的检验。**
而且数据显示，被描述的那种失败（进去就快速止损）**在这个策略里本来就很少见**。
先别加过滤器。

复现：`python3 -m cta.analysis.second_leg_down_funnel_scan --mode climax`

## 1. 交叉检验的口径

同一套分析跑两组参数，一个结论必须在**两组上同向**才算数：

- **A 组** = 出厂 leg N=4.0 / M=2.0 / w=0.15 → n=45
- **B 组** = 放松 leg N=3.0 / M=1.5 / w=0.30 → n=208

盈亏一律**以 ATR 计**，不用 R。原因很重要：入场价越靠近止损，R 越小，所有
R 口径的统计量都会**免费变好**。用 R 比较不同入场方式，会让更差的入场看起来更优。
（我第一版就是这么被骗过一次：回撤挂单的"10 根内 MFE≥0.5R"从 27% 涨到 52%，
换成 ATR 计价之后优势基本消失。）

## 2. 七个"已经跌过头"的判别量，全部不成立

按四分位分组，组内平均盈亏（ATR）：

| 判别量 | A 组 Q1低 → Q4高 | B 组 Q1低 → Q4高 | 结论 |
| --- | --- | --- | --- |
| 偏离 EMA20 | +0.02 → **−1.81** | −0.19 → **+0.80** | **反号** |
| 20 根累计跌幅 | +0.53 → **−2.88** | −0.16 → **+0.39** | **反号** |
| 这条腿本身多长 | +0.33 → **−2.42** | −0.73 → **+0.91** | **反号** |
| 连续阴线根数 | +0.26 → −2.45 | +0.39 → −0.43 | 同向但 B 组极弱 |
| 放量倍数 | −1.07 → −0.19 | −0.43 → **+1.55** | **反号** |
| 距 60 根高点 | 同上族，同样反号 | | |
| 本根波幅分位 | A 组就没有区分度 | | |

A 组上"最高四分位 0 胜率、平均 −2.9 ATR"看起来是铁证——**但那是 11 个样本一个桶**。
换到 208 个样本上，同一个量的最高四分位反而是最好的一档。这是桶噪声，不是高潮效应。

> 这正是本仓库反复踩过的坑：单一数据集上的极值不是发现。任何入场过滤器必须在
> 两组样本上同向改善才算数。

## 3. 三种入场改法，也都不成立

| 入场方式 | A 组期望 | B 组期望 | 结论 |
| --- | ---: | ---: | --- |
| 追空 收盘−1tick（现状） | −0.435 | +0.138 | 基准 |
| 回撤 +1.0ATR 挂单 | −0.226 | +0.166 | 两组都略好，但 B 组只 +0.03，且成交率掉到 67% |
| 下一根确认后再进 | +0.009 | −0.043 | **反号** |
| 止损改用信号根最高价（更紧） | −0.460 | +0.192 | **反号** |

未成交一律记 0——机会成本必须算进去，只统计成交的那部分是另一种自欺。

"下一根确认"是教科书答案（不要卖高潮那根的最低点），但它在数据上不成立：
胜率只有 13~16%，因为绝大多数信号的下一根并不满足确认条件，等于放弃了大部分样本。

## 4. 被描述的失败模式，数据里其实很罕见

| | A 组 | B 组 |
| --- | ---: | ---: |
| 5 根内被 1R 止损打掉 | 2.2% | 3.8% |
| 10 根内摸到 0.5R | 26.7% | 39.4% |

**"进去就快速止损"只占 2~4%。** 真正的失败是**走不动**：六成的入场在 10 根内
连 0.5R 都没摸到，最后被 5 根无进展止损平掉。

原因在结构里：止损是**整个形态区间的最高价**，而 leg 口径下这条腿本身就有
4~6 倍 ATR，所以止损天然离得很远，短时间内很难被打到；`NO_PROGRESS_TIME_STOP`
会先一步在**远小于 1R 的位置**把它砍掉。第一版 9 笔里 8 笔是这么退出的，
最差一笔只有 −0.74R。

**换句话说：现有设计里已经内置了高潮防御。** 它不靠事前识别高潮，而是靠
"宽结构止损 + 5 根无进展就走 + 按 R 定手数"——踩到高潮的代价是 R 的一个零头，
不是一个完整止损。所以这个失败模式在报表上表现为一串小额无进展退出，
而不是一串快速止损。

## 5. 那现在该做什么

1. **先把样本做上去，再回来问这个问题。** leg 口径刚把候选从 16 个提到 ≈85 个。
   n=45、每桶 11 个样本，settle 不了任何事。
2. 拿**真实回测输出**重做这份分析（含手续费、滑点、实际手数和资金上限），
   而不是这个扫描器的理想化行程。扫描器只适合做相对比较。
3. 如果样本上去之后高潮效应真的存在，它应该在**同一份分析的两组参数上同时出现**。
   到那时再加门，并且加的时候要能说出这道门在两组上各改善了多少。

**现在不要做的事**：按 §2 任何一个量加硬过滤。它们在 A 组上都很好看，
装上去会让下一轮回测"变好"，然后在下下轮莫名其妙地退化。
