# 2026051805 GPT-5.5 Refactor Result

日期：2026-05-18

范围：`cta/model` 两个历史大源码文件：

- `pipeline_orchestrator_source.py.txt`
- `pipeline_oot_evaluation_source.py.txt`

## 1. 目标

本次目标是把 `cta/model` 里两个超过 500 行、且以 `*_source.py.txt` 形式存在的运行时代码删除，恢复成正常 `.py` 模块。

额外约束：

- 新生成文件名以原文件名前缀为主，便于追踪来源。
- 业务 `.py` 文件保持小于 500 行。
- 拆分按逻辑职责组织，不能只靠 `exec()`、`.txt`、wildcard import 或 facade 绕过 review。
- 保持旧 public import 路径可用：`cta.model.model_pipeline`、`cta.model.pipeline_orchestrator`、`cta.model.pipeline_oot_evaluation`。

## 2. 拆分结果

### pipeline_orchestrator

保留入口：

- `cta/model/pipeline_orchestrator.py`：兼容 facade，负责同步 monkeypatch 与旧 import 路径。
- `cta/model/model_pipeline.py`：原 CLI shim 保持可用。

新增职责模块：

- `pipeline_orchestrator_base.py`：共享 imports、常量、`ModelPipelineResult`、`_WalkForwardWindow`。
- `pipeline_orchestrator_run.py`：`run_model_pipeline()` 主流程，470 行。
- `pipeline_orchestrator_cli.py`：CLI 参数解析、pool/group-pool dispatch。
- `pipeline_orchestrator_multi.py`：多 interval 调度与共享 HTF OOT 重算入口。
- `pipeline_orchestrator_dataset_prep.py`：候选样本、训练列、walk-forward split、pool feature table。
- `pipeline_orchestrator_param_grids.py`：三类模型参数网格、train/valid gap 选参。
- `pipeline_orchestrator_meta_features.py`：OOF base prediction 与 final decision meta features。
- `pipeline_orchestrator_diagnostics.py`：AUC gap、feature concentration、feature manifest、sample weight。
- `pipeline_orchestrator_outputs.py`：provenance、decile、group runtime bundle、shared HTF OOT rewrite。
- `pipeline_orchestrator_symbol_ranking.py`：ranking CSV、top-N、group-pool 分组。
- `pipeline_orchestrator_feature_curation.py`：causality manifest、leakage name filter、unaudited feature list。
- `pipeline_orchestrator_feature_meaning.py`：feature meaning lookup。

旧兼容模块如 `pipeline_dataset_prep.py`、`pipeline_param_grids.py`、`pipeline_diagnostics.py` 已改为从对应职责模块 re-export，不再反向依赖 `pipeline_orchestrator.py`。

### pipeline_oot_evaluation

- `cta/model/pipeline_oot_evaluation.py`：`_evaluate_oot_real_execution()` 主评估入口，484 行。

新增职责模块：

## 7. 风险与后续建议

- `pipeline_oot_evaluation.py` 已低于 500 行，但 `_evaluate_oot_real_execution()` 仍是复杂主函数。下一步建议继续把 timeline event loop 拆成 `pipeline_oot_evaluation_timeline.py` / `pipeline_oot_evaluation_summary.py` 这类更细模块。

- `model.md` 与 `model_baseline.md` 是 markdown，仍略超 500 行；本次用户点名的是 `cta/model` 两个大源码文件，因此未拆文档。
