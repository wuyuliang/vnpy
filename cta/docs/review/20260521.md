**未修部分（C1-residual：双条件 guard）**：

[20260520.md §2 C1 Layer 3](./20260520.md) 已明确推荐：

> MA-cross gate **只在两个条件同时满足时才生效**：
> 1. `interval == "day"`（短 interval ma_alignment 噪音大）
> 2. 该 (cluster, day) 的 `intrabar_stop_loss_pct` 已显式放宽到 > 1%（默认 1% 止损已快进快出，trend filter 仅在止损放宽后必要）

当前实现仍是**单条件**：只要用户把 `(cluster, interval)` 加入 `ma_cross_enabled_by_cluster_interval` 且 value=True 就启用，**不再检查 interval==day，不检查 stop_loss>1%**。

风险场景：

- 用户误把 `{"index|60min": True}` 加进 dict → gate 在 60min 噪音上启用 → 过度拦截
- 用户开启 `{"index|day": True}` 但保留默认 1% 止损 → gate 启用，但本意需要先放宽止损配套使用 → 出现"trend filter 拦了 short 但 long 因 1% 止损快进快出，gate 收益为 0"的低效组合
