### 推荐的修复方向（三层叠加）

**设计约束（最重要）**：MA-cross gate **只在两个条件同时满足时才生效**：

1. **`interval == "day"`** —— day 级别 MA 排列方向信号稳定；分钟级（30min/60min/15min/...）`ma_alignment` 噪音大，开 gate 会过度拦截
2. **该 (cluster, day) 的 `intrabar_stop_loss_pct` 已被显式放宽到 > 1%** —— 即用户在 `intrabar_stop_loss_pct_by_cluster_interval` 里把该簇 day 止损设为 > 0.01（如 INDEX day 0.0325）

理由：

- **默认 1% 止损**已经是"事后兜底"的快速止损，方向错也只亏 1%，不需要额外 trend filter
- **放宽止损（如 P90 3.25%）后**，方向错的单笔亏损金额会显著放大（v3 INDEX day net_pnl -4808 < v1 -4003 已验证），这时 MA-cross 才是"治本"的必需配套
- 因此 gate 与 stop_loss override 是**共生关系**：单独放宽止损 = 加大错误亏损；单独开 gate 但止损仍 1% = 多此一举；**两个一起开**才是正解

## §3 High

### **H1**：trade_filter linear 路径双重应用 class_weight

**文件**：`cta/model/training/trade_filter_model.py:120-142`、`L189`

**问题**：

```python
# L102-110：手算 balanced 样本权重
pos = int((y == 1).sum()); neg = int((y == 0).sum())
if pos > 0 and neg > 0:
    w_pos = n / (2.0 * pos)
    w_neg = n / (2.0 * neg)
    cls_weight = np.where(y == 1, w_pos, w_neg).astype(float)
# L111-118：可与 external sample_weight 相乘
if sample_weight is None:
    fit_weight = cls_weight
else:
    fit_weight = cls_weight * ext

# L132-143：linear params 又设了 class_weight="balanced"
linear_params: dict[str, Any] = {
    ...
    # 2026-05-19 注释：tree 路径已通过 cls_weight (L106-108) 做了 balanced 加权，
    # 这里同步 linear 路径。
    "class_weight": "balanced",
}

# L189：调用 linear fit 时仍传 fit_weight
linear_est.fit(x, y, model__sample_weight=fit_weight)
```

sklearn `LogisticRegression(class_weight="balanced")` 内部计算 `w_class = n / (n_classes * np.bincount(y))`，与 L106-108 完全相同。当同时设定 `class_weight="balanced"` AND 传 `sample_weight=fit_weight`（其中已包含 cls_weight）时，最终每条样本的有效权重是：

```
final_weight[i] = sample_weight[i] * class_weight[y[i]]
                = (cls_weight[i] * ext[i]) * w_class[y[i]]
                = cls_weight[i] * ext[i] * cls_weight[i]
                = cls_weight[i]² * ext[i]
```

**少数类有效权重二次方放大**。pos 占比 10% 时 cls_weight=5 → 平方后 25。linear 估计器过度纠偏，prob 整体偏 1。在 `ensemble_mode="average"` 下（默认）tree + linear 平均，整个 prob 分布右移。

**修复**（二选一）：

A. 删 linear `class_weight="balanced"`（让手算 cls_weight 单独工作）：

```diff
        linear_params: dict[str, Any] = {
            "penalty": "elasticnet",
            ...
-           "class_weight": "balanced",
        }
```

B. linear 路径不传 fit_weight，让 sklearn 内置 balanced 算法独立工作（external sample_weight 单独传）：

```diff
-        linear_est.fit(x, y, model__sample_weight=fit_weight)
+        # linear 路径用 class_weight="balanced"（sklearn 内置）做类别平衡；
+        # 外部 sample_weight 单独传，不再叠加手算 cls_weight。
+        linear_ext_weight = ext if sample_weight is not None else None
+        if linear_ext_weight is None:
+            linear_est.fit(x, y)
+        else:
+            linear_est.fit(x, y, model__sample_weight=linear_ext_weight)
```

推荐 A——更简单，与 tree 路径完全对称。
