# cta/skills/output/

## 主要做什么

**skills 子模块的离线产出占位目录**。当前为空，按需保留。

## 详细过程

部分 skill（特别是 [cta/skills/overview/](../overview/) 的实验验收、[cta/skills/live_ops/](../live_ops/) 的日复盘）可能产出 markdown / csv 等结果文件，约定落到本目录下按主题分子目录组织。

## 注意事项

- 真正的回测 / 训练产物在 [cta/report/](../../report/)；不要把它们和本目录混。
- 临时性产出可以删；长期归档需要的产物应当移到 [cta/report/](../../report/) 对应位置并在 [change_log.md](../../report/change_log.md) 留记录。
