# 日频趋势与震荡状态规则预测设计

## 1. 目标

第一阶段以 `159915.SZ` 易方达创业板 ETF 为初始分析对象，在每个交易日收盘后，
只使用当日及以前的日线价格、成交量和成交额，预测：

- 下一交易日收盘时的市场状态。
- 第三个交易日收盘时的市场状态。

每个预测输出一个限制在 `[-3, 3]` 的浮点分数，并据此映射为五种状态：

| 分数区间 | 状态 |
|---|---|
| `[-3, -2]` | 趋势向下 |
| `(-2, -1)` | 震荡向下 |
| `[-1, 1]` | 无趋势 |
| `(1, 2)` | 震荡向上 |
| `[2, 3]` | 趋势向上 |

正分表示向上，负分表示向下，绝对值越大表示方向证据和趋势质量越强。第一阶段采用
完全确定性的纯规则方法，不使用机器学习，不修改现有交易策略。完成准确率评估并确认
超过朴素基线后，第二阶段才允许接入仓位控制回测。

实现必须面向通用股票和 ETF，不得在核心计算中写死 `159915.SZ`。

## 2. 范围与非目标

第一阶段包含：

- 标准 OHLCV 数据校验和按标的独立计算。
- 历史已实现状态分数。
- 1 日和 3 日规则预测。
- 全期、逐年、验证期和样本外期准确率。
- 防穿越审计、混淆矩阵和状态切换分析。
- 最新交易日尚未揭晓答案的实时预测。

第一阶段不包含：

- 机器学习训练或自动调参。
- 分钟线、盘口、新闻、财务或跨标的截面特征。
- 对现有 EMA 策略的实际仓位修改。
- 根据样本外结果反复修改权重或阈值。

## 3. 数据契约

### 3.1 输入字段

每个标的至少需要：

```text
symbol, datetime, open, high, low, close, volume
```

`turnover` 为可选字段。输入必须满足：

- `symbol` 为非空字符串。
- `datetime` 可解析、无时区、按标的和日期唯一。
- OHLC 为有限正数，且 `high >= max(open, close)`、`low <= min(open, close)`。
- `high >= low`。
- `volume >= 0`，存在 `turnover` 时要求 `turnover >= 0`。
- 至少有 252 个连续有效交易日。

重复日期、非法价格、负成交量或不明复权口径必须立即失败，不能静默删除或向后填充。
停牌日没有有效日线时不人工补 K 线，预测跨度按该标的后续实际交易日计数。

运行器还必须接收对应交易所的开市日历。历史标签日期优先取后续实际行情行；最新预测
使用交易日历确定未来第 1 和第 3 个开市日，禁止用普通工作日近似法跨越法定休市日。

### 3.2 复权要求

历史技术指标必须使用当时已经可获得的复权信息。允许使用：

- 原始价格。
- 使用每个交易日当时已发布因子构造的连续价格。

禁止使用回测结束日的最终复权因子重新回填整个历史后，再把该结果当作历史时点输入。
数据产物必须记录价格口径和复权因子来源。运行器要求显式指定
`raw` 或 `point_in_time_adjusted`，不能根据文件名猜测。现有缓存如果不能证明每个历史
时点只使用当时已发布的因子，就不能用于本项目的历史准确率结论。

## 4. 时序与防穿越契约

对交易日 `T` 收盘后生成的预测：

- 所有特征源数据日期必须满足 `source_date <= T`。
- 当日完整 OHLCV 和成交额可以使用，因为预测在收盘后生成。
- 预测最早在 `T+1` 开盘用于决策。
- 禁止负数 `shift`、居中滚动窗口、向后填充和全样本统计量。
- 每条滚动指标都必须是以当前行为右端点的历史窗口。
- 历史未来价格只能用于生成评估标签，不能进入特征或阈值。

预测记录至少包含：

```text
symbol
feature_asof_date
prediction_horizon
prediction_for_date
max_feature_source_date
score
state
```

历史评估追加：

```text
label_date
realized_score
realized_state
```

必须满足：

```text
max_feature_source_date <= feature_asof_date < label_date
```

1 日预测的 `label_date` 是 `T+1`，3 日预测的 `label_date` 是 `T+3`。这里的
`T+1/T+3` 均指该标的后续实际交易日，不是自然日。

防穿越测试必须把 `T` 日之后的全部 OHLCV 和成交额替换为极端值，并断言 `T` 日的
1 日、3 日预测及所有分项贡献逐值不变。另需抽样使用数据前缀逐日重算，并与一次性
向量化结果完全一致。

## 5. 已实现状态分数

历史答案只由截至状态日的价格路径定义，不使用成交量和成交额。这样成交量可以作为
预测信息，而不会同时出现在答案定义中。

### 5.1 基础指标

在状态日 `D` 计算：

```text
EMA5, EMA20
Wilder ATR10
Wilder ADX10, +DI10, -DI10
ER10, ER20
log-price linear-regression slope20 and R2_20
```

Kaufman 价格效率比为：

```text
ER_N =
    abs(close_D - close_D-N)
    / sum(abs(close_i - close_i-1), i=D-N+1...D)
```

分母为零时 `ER_N = 0`。`R2_20` 使用最近 20 个交易日的对数收盘价和等距交易日序号
回归，限制在 `[0, 1]`。

定义有界函数：

```text
B(x, scale) = tanh(x / scale)
atr_pct = ATR10 / close
```

`ATR10 <= 0`、指标尚未形成或任一必需分项非有限时，该日状态和预测均保持缺失，不允许
用零或未来值替代。

价格方向分项：

```text
ema_direction =
    B((EMA5 - EMA20) / ATR10, 2)

regression_direction =
    B((slope20 * 19) / atr_pct, 3)

di_direction =
    (+DI10 - -DI10) / (+DI10 + -DI10)
```

DI 分母为零时 `di_direction = 0`。总方向证据：

```text
D = clip(
      0.35 * ema_direction
    + 0.35 * regression_direction
    + 0.30 * di_direction,
    -1,
    1
)

C = abs(D)
```

趋势质量：

```text
adx_quality = clip((ADX10 - 15) / 25, 0, 1)

Q = clip(
      0.30 * ER10
    + 0.25 * ER20
    + 0.25 * adx_quality
    + 0.20 * R2_20,
    0,
    1
)
```

### 5.2 分数映射

设 `direction_sign = sign(D)`。`D = 0` 时分数为 `0`。

无趋势：

```text
if C <= 0.25:
    magnitude = C / 0.25
```

有方向的震荡：

```text
if C > 0.25 and Q < 0.55:
    magnitude = 1 + clip(
        0.65 * (C - 0.25) / 0.75
        + 0.35 * Q / 0.55,
        0,
        1 - 1e-12
    )
```

明确趋势：

```text
if C > 0.25 and Q >= 0.55:
    magnitude = 2 + clip(
        0.55 * (C - 0.25) / 0.75
        + 0.45 * (Q - 0.55) / 0.45,
        0,
        1
    )
```

最终：

```text
realized_score = clip(direction_sign * magnitude, -3, 3)
```

该分数用于定义每个历史日期的 `realized_state`，也是后续预测的当前状态输入。

## 6. 纯规则预测

所有规则和权重在第一次真实运行前固定。第一版不得根据样本外结果修改。

### 6.1 通用有界分项

预测额外计算 Wilder `ADX5/+DI5/-DI5`、`ER5` 和最近 10 日对数价格回归
`slope10/R2_10`。公式与第 5 节对应指标一致，只改变窗口长度。

收益分项：

```text
return_N_score =
    tanh(
        log(close_T / close_T-N)
        / (atr_pct_T * sqrt(N))
    )
```

EMA5 短斜率：

```text
ema5_slope_score =
    tanh(
        (EMA5_T / EMA5_T-3 - 1)
        / (atr_pct_T * sqrt(3))
    )
```

EMA5/EMA10 方向：

```text
ema_fast_direction =
    tanh((EMA5_T - EMA10_T) / (2 * ATR10_T))
```

成交量压力：

```text
volume_pressure_N =
    sum(sign(close_i - close_i-1) * volume_i)
    / sum(volume_i)
```

成交量分母为零时压力为 `0`。活动强度使用前 20 个交易日中位数，不包含当日：

```text
volume_ratio = volume_T / median(volume_T-20 ... volume_T-1)
```

若 `turnover` 可用，同样计算 `turnover_ratio`，并取两者几何平均；否则只使用
`volume_ratio`。活动冲击：

```text
activity_shock = clip(log(max(activity_ratio, 1)) / log(3), 0, 1)
```

历史活动中位数不为正或活动比率非有限时，`activity_shock = 0`，不得因此产生无穷值。

活动量只确认或削弱已有价格方向，不能独立改变方向：

```text
alignment = sign(price_direction) * volume_pressure_N
confirmation = clip(alignment * activity_shock, -1, 1)

confirmed_direction =
    sign(price_direction)
    * clip(abs(price_direction) * (1 + 0.15 * confirmation), 0, 1)
```

### 6.2 下一交易日预测

价格方向：

```text
P1 = clip(
      0.35 * D_T
    + 0.20 * return_1_score
    + 0.15 * return_3_score
    + 0.15 * ema5_slope_score
    + 0.10 * di_direction_5
    + 0.05 * (D_T - D_T-3),
    -1,
    1
)
```

使用 `volume_pressure_5` 对 `P1` 做 15% 以内的方向确认，得到 `D1_pred`。

短周期趋势质量：

```text
Q_short = clip(
      0.35 * ER5
    + 0.25 * ER10
    + 0.20 * clip((ADX5 - 15) / 25, 0, 1)
    + 0.20 * R2_10,
    0,
    1
)

Q1_pred = clip(0.65 * Q_T + 0.35 * Q_short, 0, 1)
```

把 `D1_pred/Q1_pred` 代入第 5.2 节的同一映射函数，得到 `score_1d/state_1d`。

### 6.3 第三个交易日预测

价格方向：

```text
P3 = clip(
      0.30 * D_T
    + 0.20 * return_3_score
    + 0.15 * return_5_score
    + 0.10 * return_10_score
    + 0.15 * ema_fast_direction
    + 0.05 * di_direction_10
    + 0.05 * (D_T - D_T-5),
    -1,
    1
)
```

使用 `volume_pressure_10` 对 `P3` 做 15% 以内的方向确认，得到 `D3_pred`。

中周期趋势质量：

```text
Q_medium = clip(
      0.30 * ER10
    + 0.25 * ER20
    + 0.25 * clip((ADX10 - 15) / 25, 0, 1)
    + 0.20 * R2_20,
    0,
    1
)

Q3_pred = clip(
    0.80 * Q_medium
    + 0.20 * clip(Q_T + (Q_T - Q_T-3), 0, 1),
    0,
    1
)
```

把 `D3_pred/Q3_pred` 代入第 5.2 节的同一映射函数，得到 `score_3d/state_3d`。

## 7. 准确率评估

### 7.1 标签对齐

对 `T` 日预测：

```text
1d realized_score = realized_score at the next actual trading row
3d realized_score = realized_score at the third subsequent trading row
```

历史末尾不能形成完整标签的样本不计入对应准确率，但必须保留未标注预测，供后续交易日
补充答案。不得使用最后一个可用标签向后填充。

### 7.2 报告区间

运行时按实际数据日期输出：

- 全部有效期。
- 每个自然年。
- 开发观察期：预热结束后至 `2022-12-30`。
- 验证期：`2023-01-01` 至 `2024-12-31`。
- 样本外期：`2025-01-01` 至数据末日。

区间样本的 `feature_asof_date` 和 `label_date` 都必须落在该区间内，避免跨边界标签污染。
第一轮规则冻结后样本外期只运行一次。若根据样本外结果修改规则，原样本外结果必须降级
为研究结果，不能继续宣称为未见样本。

### 7.3 指标

1 日和 3 日分别报告：

- 五状态精确准确率。
- 五状态 balanced accuracy，即五类召回率的宏平均。
- 上涨、中性、下跌三方向准确率。
- 趋势、震荡、无趋势三结构准确率。
- 连续分数 MAE。
- 预测分数与真实分数的 Spearman 秩相关。
- 状态切换召回率、误报率、平均提前天数和平均滞后天数。
- 五状态混淆矩阵和各类别样本数。

基线至少包括：

- 持久性基线：预测未来状态等于 `T` 日已实现状态。
- 多数类基线：始终预测开发观察期出现次数最多的状态。多数类只能从开发观察期确定。

状态切换定义为相邻有效交易日的五状态类别发生变化。预测切换定义为预测状态不同于
`T` 日已实现状态。1 日预测只匹配 `T+1` 的真实切换；3 日预测在 `T+1...T+3` 内匹配
首次真实切换。一个真实切换最多匹配一次预测，未匹配预测计为误报。若某期间真实分数
或预测分数为常数，Spearman 记为 JSON `null`，不能伪造为零相关。

规则预测只有在 1 日和 3 日样本外 balanced accuracy 都超过持久性基线时，才允许进入
第二阶段仓位控制回测。否则只保留为研究指标。

## 8. 第二阶段仓位映射

本节仅固定后续接口，第一阶段不修改现有交易策略。

3 日预测决定目标仓位上限：

| `score_3d` | 新开仓 | 已有持仓上限 |
|---|---:|---:|
| `[-3,-2]` | 禁止 | 0% |
| `(-2,-1)` | 禁止 | 50% |
| `[-1,1]` | 禁止 | 50% |
| `(1,2)` | 允许 | 50% |
| `[2,3]` | 允许 | 100% |

1 日预测控制执行节奏：

- `score_1d <= -2`：立即降低一个仓位档位。
- `-2 < score_1d < -1`：禁止开仓和加仓。
- `[-1,1]`：保持，不主动增加风险。
- `score_1d > 1`：允许向 3 日仓位上限移动一个档位。
- 不允许 0% 直接升到 100%。

最终目标仓位不得高于原 EMA 策略目标和 3 日状态上限。EMA/ATR 硬退出优先于状态预测；
风险降低立即执行，风险增加继续遵守 10 个完整交易日冷却。第二阶段仍需满足最大回撤
不超过 35%、年化单边换手不超过 8 倍。

## 9. 代码边界

计划新增独立模块，不修改现有策略行为：

```text
stock/etf/regime_rules.py
stock/etf/regime_evaluation.py
stock/etf/regime_data.py
stock/etf/run_regime_analysis.py
stock/etf/tests/test_regime_rules.py
stock/etf/tests/test_regime_evaluation.py
stock/etf/tests/test_regime_data.py
stock/etf/tests/test_run_regime_analysis.py
```

核心接口使用配置和标准 DataFrame：

```text
calculate_realized_regime(bars, config) -> DataFrame
predict_regime(bars, config) -> DataFrame
attach_realized_labels(predictions, realized) -> DataFrame
evaluate_regime_predictions(labeled, periods) -> metrics
```

规则和评估计算函数必须是纯函数，不读取全局路径、不联网、不写文件。`regime_data.py`
负责把原始行情与每个交易日当时的复权因子合并成因果连续价格，并提供可选 Tushare
下载适配器。CLI 负责加载数据、选择 `symbol`、读取交易日历、验证复权声明并原子写出
审计产物。

## 10. 第一阶段输出

默认输出目录：

```text
stock/etf/output/20260725_chuangyeban_trend/
```

输出包括：

- `daily_predictions.csv`：每日 1 日/3 日分数、状态、目标日期和所有分项贡献。
- `labeled_predictions.csv`：追加历史真实分数和状态。
- `accuracy_by_period.csv`：全期、逐年、验证和样本外指标。
- `confusion_matrix_1d.csv`。
- `confusion_matrix_3d.csv`。
- `transition_accuracy.csv`。
- `summary.json`：参数、日期、样本、防穿越审计和基线比较。
- `source_audit.json`：行情、复权因子、交易日历来源及最大可用日期。

最新预测必须写出未来第 1 和第 3 个实际开市日；如果交易日历不足以覆盖第三个开市日，
运行立即失败，不得用自然日或工作日猜测。

所有 JSON 禁止 `NaN/Infinity`。输出目录非空且未指定覆盖时立即失败；覆盖运行必须先在
独立暂存目录完整生成后再事务化发布，失败时保留上一轮成功结果。

## 11. 测试与验收

必须覆盖：

- 分数边界 `-3/-2/-1/0/1/2/3` 的状态映射。
- 单调上涨、单调下跌、无方向横盘和有偏震荡的手工样例。
- EMA、ATR、ADX、效率比、回归斜率和 `R²` 与独立参考计算一致。
- 成交量只能放大或缩小已有方向，不能翻转方向。
- 1 日和 3 日标签严格按后续实际交易行对齐。
- 历史末尾未实现标签保持缺失并从准确率排除。
- 修改未来数据不改变历史预测。
- 修改未来复权因子不改变历史因果连续价格。
- 数据前缀逐日预测与全量向量化结果一致。
- 多数类基线只使用开发观察期。
- 五状态、方向、结构、balanced accuracy、MAE、秩相关和混淆矩阵可手工复算。
- 不足 252 日、重复日期、非法 OHLC、负量能和不明复权口径立即失败。
- `159915.SZ` 真实数据运行后输出文件完整，最新预测不伪造未来答案。

最终报告必须明确列出：

- 1 日准确率与持久性基线。
- 3 日准确率与持久性基线。
- 各状态样本数和混淆矩阵。
- 状态切换识别能力。
- 是否满足进入第二阶段仓位回测的准入条件。
- 数据最后日期及其最新 1 日、3 日预测分数和状态。

所有设计、计划和实现提交只进入 `feature` 分支，不合并主分支。
